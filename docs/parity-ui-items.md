# UI and item interaction parity ledger

Reference: Applied Energistics 2 19.2.18, commit `db17504a86128fdf3dae31f5fb7a112a646e0b93`. Source names below are under `src/main/java/appeng/` in that revision. Native paths are relative to `ludovic111-horizon-7f8a668/crates/horizon-client/src/` unless otherwise stated. This is a feature-family inventory, not a claim that every gesture, extension or version combination has been audited.

**Implemented** means a corresponding native path exists. **Historically exercised** refers to the bounded checkpoint checks described in [STATUS.md](STATUS.md), not a test of the current working tree. **Pending** identifies missing functionality or a behavior whose current implementation still needs a specific end-to-end comparison. Registered content, generated assets, helper tests and code paths alone do not establish parity.

## Cross-cutting gaps

- The default server-thread route has substantially more coverage than in-frame. The Provider, local terminal and confirmation paths have passed focused in-frame fixtures; one earlier Provider-related network-readiness failure did not recur and remains a timing observation; other in-frame block and face menus must be implemented or individually verified.
- `WrappedGenericStack.overrideOtherStackedOnMe` is implemented for ordinary player and generic-container menus, including component-free water/lava bucket exchange. The [physical custody fixture](../tests/world/wrapped-player-inventory.ts) passed on the Wave 8 server-thread binary for two bucket fills across restart and the ME terminal player slots. Machine player-slot handling passed a Workbench test for wrapped conversion on Wave 9, but that fixture used a creative clone which `AEBaseScreen.slotClicked` forbids. The revised Wave 10 test verified wrapped-clone refusal and ordinary creative clone, then exposed a dropped rapid bucket-to-ghost action. The [revised Workbench fixture](../tests/world/wrapped-workbench.ts) passed on Wave 11, including the deliberately queued bucket pickup and right-click, exact custody and restart. Source wrapped keys reach encoding, Interface, bus and Storage Emitter ghost consumers; broader container capabilities, exact amount gestures and remaining ghost routes need comparison.
- Interface stock amount editing has a server-thread Set/Back flow, amount bounds, unit conversion and original owner/key validation. The [block/part fixture](../tests/world/interface-stock-editor.ts) passed on Wave 11 for quantities, expressions, fluid units, an item-component stack limit, cancellation, restart and replacement-host rejection. The generic layout opens it with a shift-click on a configured slot, whereas source uses per-slot gear buttons. Other generic layouts, unsupported gestures, container strategies, accessibility and synchronization remain open.
- The pinned AE2 source targets Minecraft 1.21.1 and this Horizon tree targets 26.3. Modded capabilities, third-party extensions, Java save interchange, every platform and multiplayer setup are outside the demonstrated checks.
- A source class listed here marks the comparison surface, not a declaration that all methods in the class have been ported. Update this ledger with a test or concrete source/code evidence when status changes.
